# 四个独立研究方向：科学主张与技术路线

[研究入口](../README.md) · [技术范式](technical-basis.md) · [现象与依据](evidence-and-alternatives.md)

共同目标是让生成分布覆盖更多低 $E_{\mathrm{hull}}$ 的新颖晶体，同时保持独特性，提高严格SUN。A、B、C、D各自形成独立论文问题、技术路线和核心证据；条件生成可作为各方向的能力扩展。

## A. 化学与几何怎样共同形成正确的选择

**中心主张：**化学知识与生成中的几何信息能够共同改进科学选择，使模型在未见组合上形成更可靠的化学—结构配对。

**优先技术构思：LLM＋Diffusion/SI的双向协同生成。** LLM以结构化科学token组织元素角色、占位、配位及关系假设，保留多个选择；连续生成器形成周期坐标与晶胞的多解实现。中间几何及可用物理信息回到关系状态，支持LLM修订整组科学选择，再调整连续生成分布。

该方向要学习语义关系如何具有实际几何含义，以及几何证据如何改变尚未确定的离散决定。LLM的候选价值来自跨化学知识调用、关系表达和组合推断。技术需要让这些知识参与生成中的共同推断。

纯混合离散—连续SI是重要的竞争主路线：当主要知识来自结构和物理数据、变量状态空间已经明确时，可以直接学习联合条件场。两条路线比较知识来源、条件推断及信息交互，解释共同形成何时有益。

**独立论文贡献：**建立可迁移的语义—几何协同形成机制，解释新组合成功来自哪些知识与交互，并提高独立生成的SUN。[深入问题与证据](../programs/a-coformation.md)

## B. 局部化学知识怎样组合成新的周期整体

**中心主张：**在适当的共享物理条件下，局部化学规律能够迁移到新的连接方式与周期结构，形成此前未见的稳定整体。

**优先技术构思：具有显式周期关系的组合条件Diffusion。** 条件表达局部环境、共享原子与边、周期连接及必要的整体背景。扩散过程在统一的坐标—晶胞空间共同实现这些要求，学习局部规律和全局兼容性的联系。

技术重点是多组重叠要求的联合实现：计数成立、共享角色一致、周期结构可嵌入，并获得低能终态。LLM可用于从科学知识组织关系方案；当图式条件已明确时，条件Diffusion可直接承载研究。SI是实现同一学习对象的另一连续生成选择。

**独立论文贡献：**识别局部知识可复用的共同背景，建立跨化学、连接与原胞复杂度的组合泛化规律，并产生新的稳定结构。[深入问题与证据](../programs/b-compositional-feasibility.md)

## C. 物理经验怎样成为可复用的生成知识

**中心主张：**物理反馈揭示的补偿、重组及实现关系，可以被生成模型学习，并帮助新的化学—结构组合获得低能实现。

**优先技术构思：SI/flow的分布与路径学习。** 元素、周期位置和晶胞共同组成生成状态；真实物理计算提供条件变化、几何响应和完整后果。模型学习多个实现及它们之间的条件关系，让这些知识进入后续普通生成。

技术重点是保留来源—变化—响应—结果的对应，区分条件信息、物理过程与算法生成时间。多条件完成提供共享学习接口，实测成对关系提供额外物理信息；最终检验其在新背景中的迁移。LLM/AR科学决策＋连续生成是另一条实质路线，适合核心困难位于占位、化学角色或配位重组选择的情形。

**独立论文贡献：**解释物理计算中哪些知识可以积累和迁移，使额外物理投入改善后续独立生成的稳定新结构发现。[深入问题与证据](../programs/c-physics-to-knowledge.md)

## D. 开放发现怎样持续获得多种合格结果

**中心主张：**生成模型可以持续探索未知可行区域，学入新的成功结果并保留已学能力，从而扩大有限预算下的合格结果覆盖。

**优先技术构思：层级生成与开放探索，连接LLM/AR离散选择和条件Diffusion。** 上层选择化学、计量和结构分支，下层保留多个几何实现。材料LLM或较小的AR模型可承担上层生成；GFlowNet、集合后训练和主动探索是分配多解概率与发现预算的候选算法。

物理终态决定资格和结果身份。方法需要利用不断积累的发现历史，学习去哪里探索、哪些结构分支值得保留，以及新经验如何带来进一步发现。研究分别观察首次发现、学习后的可获得性和未用于更新的新成功。

**独立论文贡献：**建立未知资格与结果类别下的持续发现机制，并解释稳定性和有效多样性的边界如何随学习改变。可以固定结构生成器研究探索，也可以研究上下层联合学习。[深入问题与证据](../programs/d-open-successful-discovery.md)

## 四个方向的区别

| 方向 | 核心能力 | 优先方法范式 | 核心证据 |
|---|---|---|---|
| A 共同形成 | 科学选择与几何实现共同推断 | LLM＋Diffusion/SI；混合SI竞争路线 | 新组合的正确配对与有效修订 |
| B 组合可行 | 已有局部知识形成新周期整体 | 组合条件Diffusion | 跨连接、化学背景的稳定组合泛化 |
| C 物理知识 | 物理经验转成可迁移生成能力 | SI/flow；LLM决策＋连续生成备选 | 同等物理信息下的知识迁移与自主生成收益 |
| D 开放发现 | 持续发现并保持多种合格结果 | 层级LLM/AR＋Diffusion与开放探索 | 随总费用增长的新增合格类与能力保持 |

四个方向共享SUN目标和物理评价，分别形成中心主张。具体模型与预训练权重在各自范式内选择；方法的科学内容决定实现需求。
