# 中心问题的证据与选择依据

## 哪些现象最有解释力

| 现象 | 已有证据 | 对选题的含义 |
|---|---|---|
| 相同化学可以得到不同质量的结构实现 | JTF同512来源，known stable 76→85/86，每臂24未知 | 几何与晶胞的共同实现有实际改进空间 |
| 完整结构精修能够转化部分候选 | F800两组已确认SUN分别45→118/1500、77→95/1022 | 值得研究这种能力如何由逐样本过程变成可复用生成知识 |
| 辅助信号改善没有稳定转成终点事件 | 指定早段干预512配对DEV strict gain/loss均0；其它局部学习值改善终点增量弱 | 直接学习分数或小步方向可能遗漏影响完整实现的关系 |
| 重复不是已见小池的最大损失 | 86稳定→58稳定且参考新颖→53去重SUN | 稳定实现与新颖性优先，覆盖约束贯穿而非单独作为首要机制 |
| 结构数据对不同基座的作用不同 | ANCHOR的结构回流、跨生成器实现及同组成比较 | 数据质量、覆盖和条件关系值得分开研究 |

历史数据保留各自来源与评价阶段。F800中的N/U在CHGNet前，而稳定能量在后；未知标签数也发生变化。上述已确认计数是研究线索，不能直接合并为新方法的因果效果。[完整历史摘要](../evidence/historical-evidence.md)

## 前沿研究提供的正反证据

**ANCHOR。** 组成访问是其测试中的强解释，必须作为结构学习的实质竞争方案。其附录F.6在相同1000个测试组成上，KLDM的SUN为原模型17.1%、自身扩展语料微调16.5%、换成Crystalite实现相同训练组成18.9%；这些是表23的单采样种子结果和该文评价口径。扩展语料通过重放搜索组成重新实现，没有稳定或新颖阈值筛选。几何来源值得研究，但质量、覆盖与自蒸馏差异仍可解释变化。[原文](https://arxiv.org/html/2609.33407v2#A6.SS6)

**PLaID++。** 表示和后训练共同影响生成结果；坐标表示的偏好优化可以产生重复稳定结构，Wyckoff表示及相应训练改善表现。它支持稳定性信息如何进入可生成表示这一问题。[ICML 2026](https://proceedings.mlr.press/v306/xu26l.html)

**CrystAF。** 在分子晶体任务中，作者比较物理后训练、推理修复和relaxed-target回归，改善几何合理性与找回不同真实packing的效果可以分离。它提供了比“多用物理”更具体的比较：反馈究竟改变什么能力。[原文](https://arxiv.org/html/2609.36398v1)

**OMatG-flash。** 已有少步flow map及RAM物理后训练；其奖励加权的条件clean-state信息说明，单独把终点奖励传播进生成场已有方法基础。当前需要建立的增量是物理关系的内容与跨组合迁移。[原文](https://arxiv.org/html/2609.26402v1)

**OMatG-IRL。** 最新原文已经展示固定组成条件下进行物理后训练，再恢复无条件DNG。其结果中，SUN、稳定率与U/N的变化并不同步，且强化模型与原模型使用不同积分步数。当前方法将其作为强先行，研究相同信息与预算下成对关系的额外价值。[附录K](https://arxiv.org/html/2602.00424v2)

**MCFlow。** 同一模型完成组成→结构、结构→元素和无条件生成。其v3附录H.8显示，DNG模型每步强行固定元素后做CSP，不能获得正确条件生成能力；独立模态时间的训练显著改善该文CSP匹配率。这说明条件视图需要真实训练分布支持。物理干预关系怎样进一步改善新组合，是当前研究问题。[ICML 2026](https://proceedings.mlr.press/v306/seong26a.html) · [附录H.8](https://arxiv.org/html/2602.20210v3)

## 当前选择与其它方向

| 方向 | 价值 | 当前定位 |
|---|---|---|
| 化学—几何实现关系的学习与迁移 | 同时连接结构精修正结果、辅助学习负结果和近期数据来源效应 | **中心主线** |
| 单独优化组成搜索 | 已有强效果，直接影响新颖性与发现分配 | 重要基线和后续可组合能力 |
| 局部知识的周期组合泛化 | 科学意义强，需要清楚的局部覆盖和整体条件 | 中心主线的泛化问题与长期拓展 |
| 纯多样性／结果均衡 | 有利于保留U与不同成功模式 | 作为生成分布要求，不先假定它解释当前主要损失 |
| 更精确值函数、梯度或固定时机 | 可以改善特定过程 | 根据明确需要采用，当前不以辅助精度作为论文中心 |

选择依据是现象能否连接一个重要未知、方法能否学习相应对象，以及结果能否转化为新稳定结构。当前主张需要通过真实关系数据和独立生成建立，已有数字仅用于提出和比较解释。
