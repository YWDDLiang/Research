# R2评R3：让物理后果成为真实动作学习的三个修订

2026-10-09。已读完整[R3草稿](../../ideas/03-physical-outcome-learning.md)，并核对SDPO、ANCHOR与FDFO相关原文范围。R3的中心问题值得保留：同一批已付物理后果，能否让普通独立生成器学到比标量/终点接口更有用的选择？稿中固定原生动作与采集池、分开teacher新后续和student独立采样，已经给这个问题提供了清楚的比较条件。需要修订的重点是数学目标与实际日志的对应，而非再加反馈模块。

## 1. 共同parent不是整个block中的共同状态：混合Y必须对应真正可达的s

草稿采集一个约10%原生时长的block，并从内部每个Euler子步得到(s_i,a_i,Y_j)。block起点共享s，后续不同branch的物种和坐标已经分叉。§5.3再把同parent所有Y_j送给同一个s做teacher混合时，后期状态可能收到另一branch的后果；原子mask、已经揭示的species和几何都可能使这个Y无法从当前s到达。此时学习的不是P0(a|s,Y)的经验条件分布，而是未采集的反事实输入。把多个节点计成同parent数据避免了统计重复，却没有解决这个条件分布问题。

**最小修订：**共同起点可以使用所有Y的混合；block内部训练只使用实际访问到的(s_jk,Y_j)配对及该branch权重：

```
L_student = Σ_j w_j Σ_k KL[T(.|s_jk,Y_j) || π(.|s_jk)]。
```

这样先取得有效的hindsight蒸馏数据。若需要在后期同s比较多个Y，就从那个保存状态重新分支；不要把parent标签视为state相同的证明。两种版本择一写清：立即原生动作，或整个native block的序列分布。整个block不是单个Gaussian，teacher/student都应沿其实际访问状态评价转移。

这会使§5.3理想化动作边际公式成为共同起点的解释，不能自动套到每个内部状态。block影响、第一步动作影响和完整后续随机性也应按各自对象解释，避免从一次有利后果直接推出某一instantaneous drift具有同样因果作用。

## 2. 固定协方差Gaussian不是一般物理后验，forward KL也会平均不同成功动作

§5.2把T限制为native同协方差、可变mean的Gaussian与event-conditioned categorical。这是明确、可执行的policy family，但真实P0(a|s,Y)可以收缩方差或具有多个模式。一个完整物理结果会约束多步随机过程；只用Gaussian mean回归得到的是这个后验的受限近似。

更关键的是，在相同Σ下，§5.3目标

```
Σ_j w_j KL[N(μ_j,Σ) || N(μ_student,Σ)]
```

的最优mean为Σ_j w_j μ_j。它会把两个不同的有用动作平均，而不是自动保留两种动作模式。例如两个方向分别通往有用盆地，中间mean可能仍沿原来无用路径。categorical head可以混合概率，coordinate mean不具备同一种模式表达能力。因此“forward KL覆盖合格物理动作”的表述要对应实际分布族。

**最小修订：**把teacher称为“物理后果条件化的受限原生动作模型”，明确其mean/categorical输出与posterior近似差异；把KL解释为将有用后果混合投影到现有学生动作族。保留原生动作支持即可，不需要马上新增Mixture policy。新后续比较应包含这种投影：分开teacher选一个Y后执行的收益、混合mean的收益，以及student的收益。若前者好而投影差，证据指向表达族的平均化问题；若投影也好而student差，才指向蒸馏/泛化问题。这可以复用既有DEV预算。

原生cell ODE由改后的X/A状态驱动，因此复制相同cell函数是正确的，但教师动作必须完整经过原solver。直接比较teacher参数或回归误差不能代替新后续的资格结果。草稿已经安排新后续，修订后应把它视为教师可行动性的中心证据。

## 3. 先固定实际目标，再说明rich反馈的晶体增量

草稿的Boltzmann权重、uniform replay、可能的类平衡和L_base一起决定学生的实际目标；它们与单纯“同一个标量r”不完全等价。精确Bayes边际的reward tilt解释很有用，但有限8个branch的归一化、受限teacher和KL投影不继承全部理想性质。

**最小修订：**把rich→student和scalar→student定为最干净的主机制比较，二者使用完全相同Y采集池、权重、replay、teacher/student容量和原生动作族。普通PPO/NFT与endpoint SFT仍是重要能力对照，但其目标/参数化不同，应明确它们分别检验奖励更新与终点模仿，而不都叫“只换反馈的同目标”。写出当前版本保留的权重，不在主比较中临时加类平衡。

[SDPO §2](https://arxiv.org/html/2601.20802v2)已经把rich反馈放进特权self-teacher再蒸馏，故新的晶体内容应落在：带原子/时间结构的力—应力—松弛响应，如何预测可产生新资格的native动作，而不是“用hindsight teacher”本身。[ANCHOR §4与附录F.6](https://arxiv.org/html/2609.33407v1)已展示发现结构的likelihood回流；相同端点池的endpoint SFT必须保留。[FDFO原文及官方实现](https://arxiv.org/abs/2603.12893v2)通过成对完整轨迹和端点方向学习改进，它说明完整后果能监督生成，但未建立本稿的物理后验。若R3的效果仅来自优选轨迹再模仿，应据此收窄学习解释；若raw F/σ或response在同池下额外改善新后续与独立学生，才支持物理信息结构的增量。

建议新的中心表述是：**在固定原生动作族与实测采集分布下，带对象和时间结构的物理后果条件，比标量后果条件更有效地学习可执行动作投影，并提高独立新生成的strict SUN。**这是可操作、可比较的主张，不需要先宣称teacher是真实物理后验或拥有密集因果credit。

## 与R2的边界

R2改变科学字段到连续实现的对象接口，问同样信息能否被正确执行；R3保持原生接口，问后果信息怎样改善参数学习。R3可以有physics adapter，但不需要改成新的语义字段或几何完成器。两篇分别面对表示/执行和后果学习的缺口，保持这个边界有利于判断贡献。

本review提出三个必要修订，不新增科学实验或基座。已读范围：R3完整稿；SDPO §2及反馈构造；ANCHOR引言、方法概览和结构回流段落；FDFO作者摘要/官方release，未声称全篇阅读。
