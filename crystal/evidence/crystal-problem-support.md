# 晶体领域的论文问题与已有工作支撑

日期：2026 年 10 月 9 日。本表将研究问题与实际晶体文献连接。文献提供动机或近邻机制，新提案的贡献由其后续实验建立。

## 1. 生成变量互相依赖，方法应学习什么联合变化

| 工作 | 文献已经提供的能力或观察 | 对当前方案的含义 |
|---|---|---|
| [OMatG](https://proceedings.mlr.press/v267/hollmer25a.html) | 随机插值处理晶体连续变量，离散流处理物种；已有联合生成及不同过程配置 | R1 的增量需要落在源结构条件下具体化学修改与几何补偿的配对分布 |
| [MCFlow](https://proceedings.mlr.press/v306/seong26a.html) | 不同模态时间与统一多任务生成 | 不能只把独立时间或多模态联合当成新方法；应比较实际获得的修订能力 |
| [MatterGen](https://www.nature.com/articles/s41586-025-08628-5) | 联合晶体生成与条件化材料设计 | 给出成熟联合生成参照，以及结构表示与评价流程的基础 |
| [ANCHOR](https://arxiv.org/html/2609.33407v1) | 冻结 CSP 结构先验，学习组成搜索，使用相对已知集合与搜索历史的适应性新颖度 | R1 需说明源结构及局部编辑的对应关系，如何超出重新给定组成后调用 CSP |

ANCHOR 还比较了奖励微调与发现结构的似然回流，其结论依赖所测基座和评价协议。它使“已有物理结果怎样改善结构生成器”成为 R3 必须直接面对的问题。

## 2. 离散科学表示与连续结构实现之间的联系

| 工作 | 文献已经提供的能力或观察 | 对当前方案的含义 |
|---|---|---|
| [CrysLLMGen](https://proceedings.neurips.cc/paper_files/paper/2025/hash/f789a628fca473e922c806657512a20f-Abstract-Conference.html) | 语言生成与连续结构精修结合 | LLM 加 diffusion 已有先例；R2 应明确对象对应关系与连续执行接口的新增机制 |
| [PLaID++](https://proceedings.mlr.press/v306/xu26l.html) | 晶体序列表示与物理偏好学习；不同表示的稳定性与 SUN 响应不同 | 表示和后训练需要共同理解，不能把某一种偏好更新当作通用解释 |
| [CrystalFormer](https://github.com/deepmodeling/CrystalFormer) | 原生序列是 `g-(W_i-A_i-X_i)_n-L`，包含类别与连续分布头 | R2 必须遵循真实信息顺序，不假定存在完整原型前缀 |
| [CrystalREPA](https://arxiv.org/html/2605.08960v1) | 利用物理模型表征对齐晶体生成隐藏状态 | 单纯再做物理特征对齐是近邻；R2 需说明关系如何被具体几何执行 |
| [Composable Crystals](https://arxiv.org/html/2605.14769v1) | 从局部原子环境学习离散概念，并用于可控组合生成 | 可复用 concept 本身已有研究，新的接口需处理对象归属与联合几何实现 |

## 3. 物理反馈在生成学习中的位置

| 工作 | 文献已经提供的能力或观察 | 对当前方案的含义 |
|---|---|---|
| [OMatG-IRL](https://proceedings.mlr.press/v306/hollmer26a.html) | 从物理奖励学习速度／采样策略 | R3 需要与相同奖励下的普通策略学习比较，明确丰富反馈的独立作用 |
| [OMatGRPO](https://arxiv.org/html/2610.03880v1) | 离散物种通道后训练、弛豫后反馈及奖励移植实验 | 原生动作和表示决定反馈能作用的位置，不能忽略已有同类通道优化 |
| [GSS](https://arxiv.org/html/2604.27636v1) | 组合生成先验与物理力进行结构搜索 | 提高搜索覆盖的推理方法是重要对照；R3 的部署目标是学入普通生成器 |
| [CrystAF](https://arxiv.org/html/2609.36398v1) | 分子晶体中比较物理反馈进入训练、后训练和推理的位置 | 是机制近邻，需区分分子 CSP 与无机 DNG 的对象和评价 |
| [OMatG-flash](https://arxiv.org/html/2609.26402v1) | 少步晶体 flow map 及 Reinforce Adjoint Matching | 直接将少步模型或 RAM 迁移晶体已有先例，不能作为本轮单独创新 |

## 4. 发现目标与有效多样性

| 工作 | 已有证据 | 本轮使用方式 |
|---|---|---|
| [LeMat-GenBench](https://arxiv.org/html/2512.04562v2) | 统一框架下比较不同阶段、参考与物理评价 | 新实验明确共同口径，跨论文数字保留其原条件 |
| [Establishing baselines](https://arxiv.org/abs/2501.02144) | 枚举与离子替换是有竞争力的材料发现参照 | 将有能力的替换／筛选作为比较，熟悉骨架中的新稳定材料继续计入 SUN |
| [Substitution-based novelty](https://arxiv.org/html/2606.23166v1) | 将样本按有限替换搜索分为重复、替换可达和未匹配 | 用作发现类型解释，不把有限搜索未匹配等同于数学上的不可达 |
| [cSUN](https://arxiv.org/abs/2510.12405) | 连续化稳定性、独特性和新颖性评分 | 可形成训练信息，但共同主要结果仍为严格 SUN |
| [Multi-Axis Max@K](https://arxiv.org/html/2607.14962v1) | CV 中已研究模式覆盖公式和集合代表性信用 | 覆盖公式为已有原理；物理终点类别与开放可达支持是需要进一步研究的对象 |

## 5. 三篇方案如何分别承担贡献

- **R1：联合提议。** 学习给定源结构和有限化学修改时，哪些几何补偿能形成不同有效结果。
- **R2：表示与执行。** 学习科学决策、对象对应关系与连续结构之间的接口。
- **R3：反馈到能力。** 学习如何利用同一批物理过程信息改善原生动作分布，并摊销到独立采样。

三者共享最终 SUN 目标，但改变的学习对象不同。每篇都需与最接近的晶体方法比较，而不仅与迁移前的 CV 算法比较。
