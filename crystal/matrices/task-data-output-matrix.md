# 四组研究的对象—数据—输出

[研究入口](../README.md) · 2026-10-10

| 研究组 | 需要观察或学习的信息 | 关键数据关系 | 希望形成的生成能力 |
|---|---|---|---|
| A 共同形成 | 部分化学、几何与实际不确定性 | 不同条件视图与完整联合结果 | 内容相关的共同确定与兼容实现 |
| B 组合可行 | 局部环境、共享变量、周期关系与整体物理 | 已知局部知识在未见化学／连接中的实现 | 可迁移地形成新的低能周期整体 |
| C 反馈与知识 | 状态、有限行动、物理观测及续程 | 同状态干预后果、跨化学与跨请求响应 | 有效决策与可积累的生成知识 |
| D 开放多解 | 资格、物理结果身份、生成概率及历史 | 首次发现、学习保留与进一步发现 | 多种合格结果在实际预算下持续可获得 |

同一数据可以服务不同问题。例如松弛轨迹在C中用于识别行动后果，在D中用于区分原始差异与结果重复。研究角色由中心命题确定。

无条件DNG是共同主任务。CSP、条件生成、可控有限晶体子域和真实物理干预用于分离机制。来源曝光、未知状态和实际费用与对应关系一起保留。
