# 学习对象与贡献矩阵

[返回研究入口](../README.md) · 2026-10-09。各行是拟研究贡献，不是完成效果的评分。

| 提案 | 新学习对象 | 最接近的原始晶体能力 | 贡献需要体现在哪里 |
|---|---|---|---|
| R1 | 科学动作的联合提议分布 | joint generation、独立时间、composition+CSP | 源结构与具体编辑的配对补偿超越重新CSP及原生源续写 |
| R2 | 对象归属明确的科学关系执行接口 | Wyckoff序列、concept条件、特征对齐、fiber几何 | 相同信息／容量下的绑定与连续实现；响应监督的独立作用 |
| R3 | 物理后果条件原生动作分布 | 能量／力奖励适配、endpoint SFT、flow-map后训练 | 同结果池下过程信息转成普通学生的新生成能力 |

| 已有能力 | 当前使用方式 |
|---|---|
| 周期与置换对称 | 实现基础，保留物理对象等价 |
| 两时钟、联合head | 方法近邻，不以新增时钟单独主张 |
| 松弛端点与物理势 | 数据、标签和共同评价 |
| novelty／类别均衡 | 同信息对照共享的目标权重 |
| CV训练原语 | 解释学习对象，不能替代晶体论证 |
| 继承预训练与checkpoint | 报告曝光和实际配置 |
