# 共同SUN评价与费用设计

[返回研究入口](../README.md) · 2026-10-09 · 研究设计，无新实验结果。

三篇方案使用同一个科学终点：无条件请求产生更多不同的严格稳定、参考新颖结构。完整定义和拟定设置见[共同协议](../evidence/common-protocol.md)。

拟沿用CHGNet0.3.0、位置与晶胞共同FIRE、最多500步、fmax=0.05 eV/Å作为初始路线；执行前锁定实际模型、能量参考快照和环境。候选与竞争参考使用一致能量约定。

| 比较层次 | 共同内容 | 回答的问题 |
|---|---|---|
| 同信息机制比较 | 数据、条件、端点池、反馈、容量及必要预算 | 新学习对象究竟改变什么 |
| 新独立DNG | 请求范围、最终弛豫、matcher、新颖性参考 | 是否增加strict SUN及不同低能结果 |
| 泛化分析 | 继承曝光记录和组合定义 | 新能力能否用于新化学／结构组合 |
| 费用分析 | 数据收集、训练、生成、物理调用 | 收益需要多少工作 |

S/U/N均在统一最终结构上判断。原始结构指标用于解释生成与后处理。生成、解析与物理失败保留在请求分母；未知能量／参考状态保留，并报告完成上下界。

严格稳定$m\le0$、inclusive低能$m\le0.1$与严格亚稳$0<m\le0.1$分别呈现。低能训练权重不改变主要成功阈值。熟悉框架的新化学与框架变化可分层解释，继续共用SUN定义。

R1重点是相同编辑下的fresh CSP／源续写；R2重点是相同科学信息下的接口；R3重点是相同物理结果池下的动作学习。每篇加入一个预算合理的新颖性筛选／搜索参照，具体对照服务于本篇中心问题。
