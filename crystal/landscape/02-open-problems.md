# 开放能力问题

[返回研究入口](../README.md) · 2026-10-09 · 研究设计，无新实验结果。

从近期CV与晶体证据展开的六个问题仍然开放。三篇提案各选一个明确对象实施，其他问题保留为解释与后续候选。

| 问题 | 能力矛盾 | 可以学习的对象 |
|---|---|---|
| 表示双重充分性 | 理解物理环境的表示未必保留精确生成信息 | 可解码且保留物理响应的表示 |
| 化学／几何共同修正 | 高层选择需先行，完整硬承诺又可能遗漏实现 | 编辑与集体几何补偿的条件分布 |
| 组合的全局可行性 | 局部配位合理，周期关系却可能互相冲突 | 有所有者的关系与联合连续实现 |
| 反馈时机与可行动性 | 当前能量变化与最终成功可能不一致 | 当前生成动作与实测后果的对应 |
| 开放合格模式 | 已访问的成功模式不能代表全部可达空间 | 来自真实新提议的支持学习与物理结果类别 |
| 计算积累成知识 | 逐样本精修有效，但下一次生成仍犯相同错误 | 训练期物理教师到普通学生的动作蒸馏 |

[The Plan, Not the Decoder](https://arxiv.org/html/2608.21713v1)给出重要CV反例：特定系统的decoder能够忠实执行计划，错误主要来自planner。因此，晶体中需分清计划选择错误、条件传递丢失和物理实现不足，不先指定唯一瓶颈。

历史精修存在成功，也有指定小动作的零strict增量。它们用于选择能区分主要解释的科学问题，不作为全体几何路线失效的结论。[历史证据](../evidence/historical-evidence.md)

R1、R2、R3分别研究联合提议、关系执行、后果到动作知识。主张由各自同信息机制比较和新独立DNG结果建立。[提案目录](../ideas/README.md)
