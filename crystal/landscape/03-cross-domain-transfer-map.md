# 从CV研究问题到晶体学习对象

[返回研究入口](../README.md) · 2026-10-10 · 研究设计。

CV目录包含68项不同工作、69条视角记录，范围含真正文生图、编辑、类别条件基础生成和评价。迁移先识别challenge，再选择技术原语。[完整方法目录](../literature/METHOD_CATALOG_ZH.md)

| CV研究线 | 解决什么困难 | 晶体中的具体对应 |
|---|---|---|
| RAE、端到端tokenizer、pixel生成 | 好重建、好表示和好生成不完全一致 | 物理环境知识与精确原子／晶胞实现 |
| AR／连续token／masked混合 | 离散内容与连续细节分工并共同条件化 | 元素、占位与几何的耦合 |
| 异步语义—纹理生成 | 同步与完整顺序各有代价 | 哪些决定可先稳定，哪些需要几何响应 |
| 对象／关系条件与可执行表示 | 属性和关系必须落到具体对象 | 周期轨道所有者、接触关系与自由坐标 |
| 过程反馈、特权教师与轨迹学习 | 终点标量隐藏了有用的后果信息 | 力、应力与松弛响应怎样指导原生动作 |
| MeanFlow、consistency、Drifting | 推理迭代的工作能否转成可学映射 | 少步时保留多盆地可行结构分布 |
| 多样性／下游用途评价 | 单样本美观不等于有效分布覆盖 | strict SUN和不同低能新结构积累 |

[SFD](https://arxiv.org/html/2512.04926v1)的中等时间偏移优于同步和完整顺序属于ImageNet证据；[T2I-RAE](https://arxiv.org/html/2601.16208v1)与[pixel T2I实证](https://arxiv.org/html/2608.16887v1)进一步显示大规模自由文本任务需要复查小规模配方。晶体也应先问表示保留什么、接口执行什么，不直接认定某个CV loss是答案。

[Multi-Axis Max@K](https://arxiv.org/html/2607.14962v1)已经包含模式占据公式及边际收益。晶体的新增困难是结果类别由物理弛豫产生、开放区域的资格未知；公式本身不作为新算法。
