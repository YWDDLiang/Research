# 晶体生成的三种候选方法

[研究入口](../README.md) · [研究问题](../programs/README.md) · [共同评价](../evidence/common-protocol.md)

以下方法是尚待实验验证的技术候选。它们分别改变联合提议、科学对象到几何的接口，以及物理后果进入生成学习的方式。

| 方法 | 学习对象 | 正文 | 原始来源 |
|---|---|---|---|
| R1 | 源结构上的化学编辑与匹配几何补偿 | [联合修订生成](01-revisable-joint-generation.md) | [R1 来源](../evidence/sources-r1.json) |
| R2 | 科学字段的对象绑定与连续结构执行 | [表示与执行](02-scientific-representation-execution.md) | [R2 来源](../evidence/sources-r2.json) |
| R3 | 物理后果条件化的原生动作学习 | [后果条件动作学习](03-physical-outcome-learning.md) | [R3 来源](../evidence/sources-r3.json) |

方法说明保留数学对象、信息来源、近邻区别及关键科学比较。主要结果均为新的独立生成批次中严格 SUN 和不同低能新颖结构的积累；条件正确率、预测精度和修复效率用于解释机制。
