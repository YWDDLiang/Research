# R2｜从科学选择到精确物理结构：对象绑定与响应保持的晶体生成接口

**定位更新（2026-10-10）：本文件保留为前轮技术备选。当前研究以[六条挑战](../landscape/02-open-problems.md)和[四组科学问题](../programs/README.md)为主线，方法实现不预先限定论文问题。**

**提案状态：2026-10-09，研究设计，尚无新实验结果。**

**主基座：CrystalFormer Alex20s multitask，epoch_044000.pkl。**

**验证基座：最多一个，公开PLaID++ Wyckoff模型。**

**中心问题：科学决策中的元素、轨道和局部关系，怎样通过可执行的离散—连续接口实现为低能周期结构？**

## 提案摘要

晶体生成模型已经能够表达化学组成、空间群、Wyckoff轨道和局部环境，也能够通过连续生成或物理松弛改善几何。然而，对科学选择的表征、对具体周期对象的对应和对精细几何的执行仍是不同能力：看似正确的描述可以落到错误站点，几何相近的输出也可能产生很不同的力与应变响应。本提案研究对象绑定且保持物理响应的生成接口。以已发布CrystalFormer为主基座，在其真实的站点级交错序列中加入附属于具体轨道的邻居/配位摘要和轨道对关系；新增连续完成头在保留这些对象对应的条件下，联合生成晶格与Wyckoff自由坐标。训练同时学习结构分布、关系实现和局部方向能量响应，使接口保持科学选择所要求的关系，并分辨影响物理实现的几何差别。最终目标是增加同一物理协议下的严格stable、unique、novel晶体。研究将用正确参考条件与自主生成条件的交叉比较，分别定位计划选择、条件传递和几何执行的贡献。本文提出具体方法与实验设计，不报告尚未取得的性能增益。

## 1. Introduction：生成科学描述与生成物理对象之间的距离

材料发现依赖的是新化学选择的精确结构实现。改变一个站点的元素或局部连接，适合的键长、配位与晶格会随之变化；这些变化必须在同一个周期结构中成立。语言、对称表示和局部环境特征提供了有用的科学压缩，但最终的能量取决于具体原子和晶格。生成模型需要同时具备选择合理关系的能力，以及把关系转成精确几何的能力。对称成立、描述合理和原子不重叠分别支持一部分能力，整体物理终态才决定其发现价值。

这一问题已有直接的晶体证据。CrysLLMGen先用LLM生成元素和粗几何，再固定元素用DiffCSP式模型细化；其§7明确指出两个模块独立训练、没有相互作用。这说明化学知识与连续实现的接口已经重要，也留下了能否学习更紧密对象关系的问题。[CrysLLMGen，§4、§7](https://arxiv.org/html/2510.23040v1)。CrystalReasoner进一步生成对称、局部环境和预测性质的thinking tokens，但§3.2指出这些信息不能保证输出符合所描述的先验，仍由终态标量奖励共同优化。这里的缺口是描述的执行关系，而不只是缺少科学文字。[CrystalReasoner，§3.1–3.2](https://arxiv.org/html/2605.14344v1)。

物理表示也提供了另一条证据。CrystalREPA通过形成能探针发现生成表示与MLIP表示有差距，并用元素感知的原子特征对齐改善生成。其§4监督对象是噪声状态的原子hidden state与干净结构的MLIP特征，推理流程保持原样。[CrystalREPA，Fig.1、§4–5](https://arxiv.org/html/2605.08960v1)。这个结果使“再做MLIP特征对齐”不足以构成本提案。R2要问得更进一步：这些物理语义是否保留了具体站点对应，以及连续头是否能区分局部位移和应变导致的物理响应？

项目历史强化了这个问题的实际意义。在DLM33的40个匹配TRAIN来源中，保存的teacher与自由生成student原始force-RMS均值分别为0.179845和24.07336 eV/Å；该审计是既有几何交叉，不能定位自由生成误差的唯一来源。DLM19显示typedPlan有小几何响应，DLM20整体gate失败，DLM22的volume-Plan没有提高strict SUN。它们提示：条件响应与目标能力之间还缺少一条可检验的执行链。这里不默认计划正确：好的executor可能忠实实现了不合适的选择，好的计划也可能在生成接口中丢失。

因此，本提案把**对象绑定**和**物理响应保持**作为连续实现接口的两个明确要求。前者规定科学字段属于哪一个周期轨道、哪一对对象；后者规定几何实现不仅接近训练坐标，还应保留这些对象在局部位移与晶格应变下的能量变化。预期中心主张是：**在同样科学信息与物理监督下，保留对象对应和局部物理响应的接口，比无对象身份的条件向量或仅特征相似的对齐，更可靠地实现新化学—结构组合，并增加严格SUN。**这个主张需要自主生成与物理终态证据共同支持。

## 3. 问题定义与确切主基座

晶体为x=(A,X,L)，周期等价包括允许的原子排列、原点和等价晶胞选择。使用规范空间群setting中的轨道对象

```
O = (g, {(i, W_i, M_i, A_i)}_{i=1}^m),
y = (ℓ, ξ_1, …, ξ_m),  ξ_i ∈ T^{d_i},
x = Φ_O(y).
```

W_i为Wyckoff位置，M_i为重数，d_i为该轨道的自由度；Φ_O按空间群操作展开原子，ℓ位于与g相容的晶格参数chart。模型学习多个几何实现的条件分布；给定O不意味着固定物理框架，也不意味着指定关系一定可行。

**选定发布版本。** [官方MODEL_CARD](https://github.com/deepmodeling/CrystalFormer/blob/main/MODEL_CARD.md)给出Alex20s multitask权重：
[alex20s/multi/epoch_044000.pkl](https://huggingface.co/zdcao/CrystalFormer/resolve/main/alex20s/multi/epoch_044000.pkl)。本次只核实发布声明与HF文件元数据，没有下载。文件166,094,129 bytes，LFS SHA-256为847e8f3962226d0539722c851bd615479d9c7fc2d5be9112898c1cdd2b7b700a。官方源码main当前commit为31bb734a3fd006af49a021921839061e6184cbf1。模型约13.8M参数，16层、8头、d=256，Kx=16、Kl=4、n_max=21；支持DNG/CSP。

Alex20s约1.7M材料，官方筛选是E_hull<0.1 eV/atom、**常规胞最多20个Wyckoff sites**，不是最多20个原子。主研究先在该发布split内的原胞≤20原子子域建立共同数据/评价，再扩展原有site范围。所有基座变体使用相同继承checkpoint、增量数据与元素/原子数条件。新颖性参考包含继承训练数据的声明范围，不能只对增量小集合去重。

## 4. 方法：对象绑定的科学字段与连续完成分布

### 4.1 真正新增的科学对象字段

保留原基座的站点交错，新增两种表示：

1. **轨道局部字段S_i**：按邻居元素分组的近邻数/软计数、第一壳层径向分布粗bin、低阶角度/配位形状摘要。字段所有者是(i,W_i,A_i)，而不是一段全局“六配位”描述。
2. **轨道对关系R_ij**：i与已生成j的接触重数及径向粗bin，保留(i,j)的对象对应。周期邻居由完整展开结构提取，跨胞接触纳入标签；不只检查单胞内部。对有明确接触重数的字段，用M_i n_ij=M_j n_ji的计数一致性作可计算约束。

这些字段从真实结构自动提取，采用可解释低维摘要，不新训一个VQ concept codebook。它们的作用是保留科学选择和具体变量的对应。粗bin避免把全部真实坐标重新编码成“计划”；同字段下仍有多个几何实现。

新的采样顺序是

```
g – [W_i – A_i – S_i – R_{i,<i} – X_i^draft]_i – L^draft。
```

S/R预测head读取真实历史state；新字段的embedding通过带orbit/pair所有者的attention adapter进入后续W/A/X/L预测。前向的未完成邻居需求保留为预测要求，不能因尚无对应对象就当作已满足。终止前汇总完整关系状态C=(O,S,R)，由连续完成头实现它。这是新增架构，不能假设原CrystalFormer已经有“全部prototype前缀”。

### 4.2 连续head怎样依赖科学对象

保留原生von-Mises坐标head与Gaussian晶格head形成draft y^0。新增完成头q_φ由对象状态encoder和连续输出层组成：

```
q_φ(y | C, y^0)
  = q_φ(ℓ | C, y^0)
    ∏_i q_φ(ξ_i | ℓ, C, y^0, ξ_<i).
```

先实现晶格再生成自由坐标，使关系中的距离要求能读取当前实际晶格。对象encoder包含所有轨道node和pair R_ij；第i个自由坐标head的query明确携带i、W_i、d_i，读取属于i的字段及连接到i的pair消息。整个过程保留free-coordinate chart，Φ_O负责确定性空间群展开。分布采用多模态wrapped-Gaussian自由坐标head和相容晶格head；不把不同模式的坐标先平均成一个结构。

q_φ是在同一科学选择下生成精确实现的分布，不改变O中的化学/对称选择；主要贡献限定在表示与执行接口。不同O的自主选择由新增科学字段的CrystalFormer负责。主文不加入独立化学编辑kernel，也不加入过程RM或预算搜索策略。

### 4.3 训练输入与结构/关系监督

训练结构x*解析为O*、y*、S*、R*。执行训练的draft来自真实结构的对称相容小扰动，或基座在给定O*下的几何完成；它们只作为q_φ的条件，正确目标始终是y*。完整自主生成流另外用于终态alignment，不能把其中的坏draft或未经对应的物理终点当正SFT目标。

```
L_gen = -log p_θ(O*,S*,R*,y*) - log q_φ(y* | C*,y^0).

L_bind = Σ_i ||Q_i(Φ_O(ŷ)) - S_i*||²
       + Σ_(i,j) ||Q_ij(Φ_O(ŷ)) - R_ij*||²。
```

Q由周期邻居、径向/角度basis和轨道汇总计算，训练用平滑版本，评价用离散化规则。Q_i与S_i按对象对应比较。原生joint NLL只监督真实科学字段和真实几何；可增加保持O*的几何扰动前缀，但不将不相容离散前缀配给参考后缀。自主前缀的学习更新在4.5单独定义。draft与x*的配对保留来源身份，不把任意同式晶体强配成相同结构。

### 4.4 物理监督：保持局部方向响应，而不仅对齐语义特征

在原子自由位移方向与相容晶格应变方向δ上，定义正负两侧的每原子有限能量增量

```
Δ_δ^± E(y)
 = [E_ψ(Φ_O(y±εδ)) - E_ψ(Φ_O(y))] / N,

R_δ(y) = (Δ_δ^+ E(y), Δ_δ^- E(y)),
L_resp = E_(δ) ||R_δ(ŷ) - R_δ(y*)||²。
```

δ在实际chart中按Cartesian位移/无量纲应变归一化，保证量纲与对象对应明确。两个增量的奇分量近似方向力/应力，偶分量近似沿δ的谐振曲率；在平衡点一阶力接近零时，偶分量仍能区分软硬响应。E_ψ用冻结的保守MLIP，主实现采用CrystalFormer已有支持的orb-v3-conservative-inf-mpa。训练仅对这三个能量值求一阶输入导数，不反传完整松弛，也不新增独立曲率loss。响应监督在靠近已知几何的completion小批次使用，多个模式按对y*的posterior responsibility分别监督；所有对照用相同扰动幅度、方向及能量调用。

总体目标为L_gen+λ_bind L_bind+λ_resp L_resp。λ由验证集共同选择；物理样本数与调用成本对各比较一致。响应监督训练的是解码结构对自由度的敏感性。CrystalREPA特征对齐作为同teacher、同数据的直接对照，检验这个额外对象是否有必要。

### 4.5 自主生成与目标对齐

新材料生成完整流程是：采样g与站点交错决策→得到draft和有对象对应的C→q_φ采样连续实现→标准物理评价。既可无组成条件DNG，也可给定组成做机制诊断。用户无需提供正确计划。

增量训练后可使用基座现成终态alignment更新θ和φ；自主生成前缀通过其实际完整结果的共同utility更新联合log p_θ+log q_φ，与真实结构joint NLL分开。所有方法共享同一终态反馈算法与物理预算，不能把生成draft似然本身当作成功标签。针对同一O的多完成，物理结果反馈S/R选择是否适合；它们是随机完成的证据，不把一次失败变成整条关系不可行。最终评价汇总全部请求，并按实际终态去重和判断新颖性。

## 5. 研究问题、数据与评价

**主科学问题。** 在共同物理信息下，对象绑定和响应保持是否改善新化学—结构组合的实现，而不只是提高对给定参考计划的服从？

**数据。** 使用选定CrystalFormer发布split，先在原胞≤20原子子域训练新增模块；形成化学—轨道组合holdout，保持继承预训练曝光单独记录。真实关系从structure/space-group解析和周期邻居计算提取。物理扰动标签使用固定MLIP产生，部分终态用自洽DFT检验。继承预训练已见的样本不重新包装成零样本OOD；组合holdout主要评价新增接口的跨组合适应。

**主评价。** 固定一套原子数/元素范围、松弛设定、同理论水平的候选/竞争参考能量、StructureMatcher与novelty reference，报告严格E_hull≤0 eV/atom的SUN、U/N、E_hull分布及不同化学/结构类别。原始输出与松弛终态分别记录，主结论用终态SUN。未知/失败状态保持独立，全部请求进入分母；训练物理调用与部署调用分别列出。新化学装饰和新框架分别描述，不改写主指标。

**主要比较。** 主结果集中在同一CrystalFormer继承版本：原生模型、同信息的普通全局科学条件、绑定字段无响应监督、绑定字段+普通MLIP特征对齐、完整方法。全局条件收到同样O/S/R/draft及MLIP监督，q_φ的层数、宽度、分布族和参数预算相同，只把对象专属路由改成普通全连接条件attention；所有对照共享同一space-group chart与Φ_O。再加原生几何head+同样绑定/响应监督、原生draft+相同物理松弛，区分对象路由、完成容量、监督和修正预算。最多以PLaID++公开Wyckoff模型验证跨上游表示的方向。

## 7. 实施路径与交付

第一阶段读取并固定官方checkpoint/源码配置，完成标准胞—轨道索引—自由参数的往返数据；复现原生采样和当前共同评价。主要工程入口是crystalformer/src/transformer.py、sample.py及现有GLXYZAW解析，新增字段不能改变原有W/A/X的身份。

第三阶段加入物理扰动响应小批次，完成真条件/预测条件/所有者交换比较，再用完整DNG流评价strict SUN。必要检查服务于索引、周期等价和已发现的几何误差，不建立冗余测试层。

第四阶段完成同终态alignment及最多一个验证基座，组织论文图表与代表性结构。结果应回答“改善发生在哪里、哪些新组合被实现、是否增加不同低能新颖结构”；没有SUN收益时，保留关系执行或物理响应结果的实际范围并更新中心判断。
