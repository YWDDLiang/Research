# 四组研究纲领：从重要问题到晶体生成能力

A、B、C、D分别形成独立中心主张、技术路线与论文问题。各自的生成范式见[四方向方法构思](../focus/README.md)与[LLM、Diffusion、SI的分工](../focus/technical-basis.md)。

更新：2026-10-10。[研究入口](../README.md) · [六条原始挑战](../landscape/02-open-problems.md)

目标保持为：让生成分布覆盖更多低 $E_{\mathrm{hull}}$ 的新颖结构，同时保持独特性，提高严格SUN。熟悉框架的新稳定化学组合继续计入发现。

四个研究主题提出竞争解释与候选技术路线；方法主张尚待实验验证。每组均包含现象和原始论文、竞争解释、明确的科学对象、三条不同技术路线，以及成功后能够建立的知识与能力。

## 贯穿四组的判断

> 即使一种方法实现成功，它回答了什么值得顶会讨论的重要问题？

论文可以侧重一种新能力、可迁移机制、生成过程规律或对重要困难的解释，按中心主张组织必要证据。实现与辅助指标说明过程；新的稳定结构和对能力来源的解释支撑科学价值。

<a id="a"></a>
## A. 化学选择与几何实现，能否共同形成？

对应挑战1、2。精确的分阶段模型也能表达正确联合分布。真正的问题是有限数据、容量与信息下，哪些条件交换能够提高新组合的学习和实现能力。深入分析保留组成分配、条件不兼容、表示不足和过程信息四种解释。[阅读全文](a-coformation.md) · [来源](sources-a.json)

<a id="b"></a>
## B. 局部化学知识，怎样形成未见但整体可行的晶体？

对应挑战3，联系1。局部邻域共享原子、边和晶格，组合受到计数、周期闭合与整体物理响应约束。研究局部知识在什么条件下可迁移，以及全局信息需要保留什么。[阅读全文](b-compositional-feasibility.md) · [来源](sources-b.json)

<a id="c"></a>
## C. 物理反馈怎样变成有效决定与可积累知识？

对应挑战4、6。反馈可靠时，生成器未必仍有改变结果的选择；仍有选择时，反馈又未必可靠。研究这种关系如何随科学状态变化，以及干预后的物理响应能否跨化学和生成任务迁移。[阅读全文](c-physics-to-knowledge.md) · [来源](sources-c.json)

<a id="d"></a>
## D. 物理优化能否扩大有效解空间，同时保留多种成功？

对应挑战5，联系6。区分提高合格率、重新分配已有成功概率与学习新的合格结果。研究真实物理可行性、数据知识、表示冗余及学习目标各自如何影响有限预算下的发现分布。[阅读全文](d-open-successful-discovery.md) · [来源](sources-d.json)
