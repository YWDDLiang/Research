# 四组研究纲领：从重要问题到晶体生成能力

更新：2026-10-10。[研究入口](../README.md) · [六条原始挑战](../landscape/02-open-problems.md)

目标保持为：让生成分布覆盖更多低 E_hull 的新颖结构，同时保持独特性，提高严格 SUN。熟悉骨架中的新稳定化学组合仍然有发现价值。

当前研究以六条挑战和下面四组问题为主线。R1/R2/R3 保留为[技术备选](../ideas/README.md)，它们的实现细节不预先决定研究问题。

## 贯穿四组的判断

> 即使一种方法实现成功，它回答了什么值得顶会讨论的重要问题？

需要建立的可以是一种新的能力、可迁移机制、关于生成过程的规律，或对已有困难的实质解释。实现、预测和辅助指标是研究的一部分，中心主张还要连接到新的稳定结构发现。

<a id="a"></a>
## A. 化学选择与几何实现，能否在生成过程中共同形成？

对应六条挑战中的 **1、2**。

一个晶体的高层选择，可能只有在部分几何形成后才能判断是否合适；几何又依赖这些选择继续形成。重要问题是怎样保留必要的备选，利用逐渐形成的结构信息共同修正，并形成一致的化学—几何方案。

研究对象是互相依赖的科学决定如何逐步形成。联合表示、交错生成、可修订变量与状态驱动交互是不同技术路线。方法应解释它改变了什么决策能力，而不把研究收束为某个固定顺序、时间窗口或事后替换操作。

<a id="b"></a>
## B. 能否复用局部化学知识，形成未见但整体可行的晶体？

以六条挑战中的 **3** 为主，联系 **1**。

材料中存在可复用的元素环境与配位关系，但把它们组合起来仍需满足周期结构、共享晶胞和相竞争。研究应回答模型究竟复用了哪些知识，哪些局部选择能够共同实现，以及哪些相互作用决定了组合的成功与失败。

研究对象是知识复用与全局物理兼容性。局部表征、关系建模、约束生成与物理反例学习是候选机制。关键结果应体现新组合的成功实现，并解释泛化的来源与范围。

<a id="c"></a>
## C. 物理反馈怎样变成有效的生成决策与可积累知识？

对应六条挑战中的 **4、6**。

重要决定可能很早形成，而可靠物理信息通常要到结构较完整时才出现。研究应说明反馈怎样作用于仍有意义的选择，以及一次昂贵计算怎样帮助下一次不同的生成任务。

可以学习化学选择需要改变的环境、几何修复规律、对终点没有影响的局部下降，以及可跨材料复用的物理响应。教师蒸馏、过程模型和搜索回传是不同实现。论文需要证明反馈形成了可迁移的决策能力。

<a id="d"></a>
## D. 物理优化能否扩大有效解空间，同时保留多种成功结果？

以六条挑战中的 **5** 为主，联系 **6**。

科学发现需要多个不同的有效答案。研究应区分优化提高了已有成功的生成概率，还是使更多合格结构在实际预算下变得可达。晶体的合格结果事先未知，结构身份经过物理过程后才清楚，因此这是开放的多解生成问题。

需要研究未知有效结果怎样被发现、学入模型并保持可达。覆盖目标、分布学习、主动探索和搜索摊销各自承担部分职责。方法应同时解释成功资格与有效多样性的形成。

## 六条挑战与四组主线的关系

| 原始挑战 | 主要研究组 | 关联 |
|---|---|---|
| 1 科学语义到物理结构 | A | B 的知识表示 |
| 2 化学与几何的确定及回改 | A | C 的反馈时机 |
| 3 局部化学到整体可行性 | B | A 的实现过程 |
| 4 物理反馈与有效决定 | C | A 的可修订性 |
| 5 未知合格结果的保持和扩大 | D | B 的新组合 |
| 6 额外计算积累成能力 | C、D | 支持其它组的知识获取 |

四组保持各自中心问题，可比较多种实现。技术选择应由学习对象和证据推出。Conditional generation 是可选功能，也可以用于分离机制；共同主要目标仍为独立生成的严格 SUN 与低能新结构覆盖。
