## 1. 四组分别要解释哪种能力

| 研究组 | 需要解释的能力 | 即使模型实现成功，最有价值的新认识是什么？ |
|---|---|---|
| A 共同形成 | 在化学和几何均不完整时，保持并形成相互兼容的选择 | 哪些信息与数据条件下，双向共同形成比准确的分阶段生成更容易学到新可行组合 |
| B 组合可行 | 复用已学化学环境，形成未见的周期整体 | 局部规律在什么共享条件下可组合，哪些全局依赖决定它们能否转移 |
| C 反馈与知识 | 用物理信息改变仍有作用的决定，并让下次任务受益 | 可预测性与可行动性如何相遇，以及哪些干预知识能够跨化学和续程迁移 |
| D 开放多解 | 让更多合格结果在有限计算下可被获得，并保持已有成功 | 稳定性与有效多样性的冲突来自哪里，哪种学习能移动实际发现能力的边界 |

共同评价是严格SUN、低能新颖结果与独特性。四组的差别在于解释什么、学到什么。主表的进步与机制证据共同支持论文中心主张。

## 2. 从技术基座的能力选择研究平台

| 技术平台 | 特别适合观察什么 | 需要保留的竞争方案 |
|---|---|---|
| OMatG／MatterGen等原生联合生成 | 元素、位置和晶胞在同一过程中怎样相互影响 | 高质量组成策略＋CSP，检验收益是否已经来自组成分配 |
| MCFlow式多模态条件场 | 不同已知信息下的联合完成与条件兼容 | 同一信息条件下的单方向生成，检验双向学习的必要性 |
| CrysBFN式belief生成 | 模型当前确定了什么，仍有哪些可行选择 | 相同开放选择但无内容反馈的探索，分开信息与熵的作用 |
| Wyckoff／周期图／局部concept与连续实现 | 科学关系、局部复用与整体几何之间的联系 | 有能力的检索替换、原生坐标生成，识别模板和知识的贡献 |
| LLM或AR与连续token／flow结合 | 化学结构知识、条件上下文与精细实现的责任分配 | 原生联合模型与普通条件生成，避免把接口复杂度当能力 |
| 物理引导搜索、过程学习、后训练 | 反馈作用的时机、动作后果及知识回流 | 同物理数据的端点学习和简单搜索，识别过程信息的价值 |
| QD、GFlowNet、粒子式分布探索 | 多种合格结果的形成、概率分配和保持 | 组成重分配、档案重放及预算相同的筛选 |

这些平台不必拼成一个大系统。平台选择应使竞争解释能够被实际区分；具体版本、数据规模和预算在中心命题清楚后确定。

## 3. 四种论文中心论题的候选写法

### A：相互依赖的科学决定如何共同形成

**候选题意：**“学习化学与几何的兼容形成过程”。

论文从一个清楚的事实开始：完整联合分布既可由分阶段采样实现，也可由联合演化实现。实际差别出现在有限数据、近似表示和不完整信息条件下。研究识别两种条件视图何时无法共同实现，或哪些几何信息能帮助尚未确定的化学选择，并提出相应生成原则。

中心主张可以是：一个以兼容信息状态为依据的生成过程，在新化学—几何组合上提高学习效率和物理成功率。最重要的结果是规律能够解释并预测共同形成何时有收益，随后在独立生成中得到更多SUN。理论、表示学习或过程设计可以各自成为技术中心，取决于主导解释。

### B：局部化学知识何时能够组合成周期整体

**候选题意：**“学习可组合的物理知识及其全局成立条件”。

论文将组合泛化放到共享原子、周期回路和统一晶格中研究。局部环境相似并不自动保证兼容；反过来，允许全局通信也不说明模型利用了可迁移规律。方法学习哪些局部知识可复用、需要哪些共同条件，以及关系如何变成实际几何。

中心主张可以是：适当的共享条件使局部知识在未见化学或连接组合上成为有效的生成机制。核心贡献由局部—全局的条件规律、实现该规律的生成方法、以及新增稳定组合共同构成。熟悉框架上的新化学和新的连接形式都具有价值，分别解释来源。

### C：从物理观测获得可迁移的生成决策能力

**候选题意：**“在可行动的阶段学习物理反馈”。

论文研究反馈什么时候能区分仍然有用的选择。能量预测准确、力下降快和最终发现之间存在不同的信息关系。模型需要掌握某类环境在某种有限行动下怎样响应，并把这些关系带到新的生成请求中。

中心主张可以是：学习条件化的物理干预知识，使有限物理计算同时改善当前决定和未来生成。关键结果是跨化学、来源或续程仍成立的响应迁移，以及累计费用下更好的发现能力。科学决策时钟、响应学习、决策价值选样是不同主线，可以由其中一条支撑完整论文。

### D：在未知可行域上学习持续发现多种答案

**候选题意：**“学习物理结果上的开放生成分布”。

论文面对未知的合格结构集合。生成器的表示、概率分配和弛豫过程共同决定最后能看见哪些结果；优化稳定性时的重复增长，可能来自不同原因。研究分开已知成功的重新加权与新生成知识的形成，探索如何同时增加成功概率和合格结果覆盖。

中心主张可以是：一种学习原则让物理反馈扩展有限预算下可获得的合格结果，同时保留已学成功；这种变化可以被结果分布和知识更新解释。方法可从开放集合学习、组成与条件能力的适应，或物理映射后的概率测度切入。核心贡献是发现能力边界的变化及其原因。

## 4. 当前选择与关键比较

首先选一个有充分原文与已有数据支撑、且存在真正竞争解释的现象。A优先观察化学—几何相关性在形成过程中的作用；B优先观察局部已知但整体不同的新组合；C优先观察同状态下不同有限行动的完整后果；D优先整理物理终态的合格概率与重复分布。

随后用能够区分主要解释的研究比较确定学习对象。旧结果用于形成假设；已有数据能回答的先分析，缺少的信息再通过必要新实验获取。路线选择依据是哪个问题能同时提供重要认识、可实现的技术贡献和有意义的新稳定结构。

当前选择以物理关系学习为中心：A提供联合条件实现平台，B提供未见组合的迁移问题，C提供有物理依据的关系监督，D规定多种合格结果的发现目标。具体方法以OMatG为主基座，学习多条件实现和真实配对响应，并在独立DNG中评价。详见[技术基座与关键比较](../focus/technical-basis.md)。
